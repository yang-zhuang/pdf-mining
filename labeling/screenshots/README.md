# Label Studio 截图文件夹

## 文件夹用途

此文件夹用于存储 Label Studio 标注平台相关的截图，包括但不限于：

- 界面设置和配置截图
- 标注模板示例
- 标注工作流程说明
- 问题和解决方案的可视化记录
- 标注结果示例

## 命名规范

所有截图文件请遵循以下命名格式：

```
YYYY-MM-DD_description.ext
```

其中：
- `YYYY-MM-DD`：截图日期（四位数年份-两位数月份-两位数日期）
- `description`：简洁的英文描述（使用下划线连接多个单词）
- `.ext`：文件扩展名（如 .png, .jpg）

### 命名示例

- `2026-02-16_initial_setup.png`
- `2026-02-16_three_column_template.png`
- `2026-02-16_annotation_example.png`
- `2026-02-16_label_config_json.png`
- `2026-02-16_project_settings.png`

## 建议存储的截图类型

1. **项目设置**
   - 项目创建和配置界面
   - 标签设置和分类定义
   - 用户权限设置

2. **标注模板**
   - 不同类型文档的标注模板
   - 标注区域示例
   - 标注规则说明

3. **工作流程**
   - 标注步骤说明
   - 数据导入/导出界面
   - 批量操作流程

4. **问题记录**
   - 遇到的问题截图
   - 错误信息
   - 解决方案前后对比

## 注意事项

- **隐私保护**：上传截图前请确保已隐藏或模糊处理所有敏感信息，包括但不限于：
  - 个人身份信息（姓名、地址、电话、邮箱等）
  - 公司机密信息
  - API 密钥和访问令牌
  - 账户密码

- **文件大小**：建议使用 PNG 格式以保持清晰度，文件大小控制在 2MB 以内

- **图片质量**：确保截图清晰可读，重要信息不被遮挡

- **相关性**：只保留与项目相关的截图，定期清理过时或不再使用的文件

## 文件组织

如需更好地组织文件，可按以下结构创建子文件夹：

```
screenshots/
├── setup/           # 项目设置相关
├── templates/        # 标注模板
├── workflows/        # 工作流程
├── issues/           # 问题记录
└── examples/         # 标注示例
```
